# Shift Stability Implementation Plan

> Implement with test-driven development: observe each new regression test fail
> for the intended reason before changing production logic.

**Goal:** Stabilize Race/Offroad upshifts and brake downshifts while keeping
post-13.2.2 correctness fixes.

**Architecture:** Keep decisions inside `TCULogic`. Add small helpers for
target-gear RPM safety and RPM-window trend detection so selection, validation,
and anti-hunting all share consistent thresholds.

**Stack:** Python 3.12, pytest, Ruff; pnpm/Node 24 for CI-parity checks.

---

## Task 1: Brake target regression tests

**Files:**

- Modify: `tests/test_race_downshift.py`

Add tests proving that a projected-speed target is clamped when its RPM at the
current speed exceeds 98% of the effective ceiling, that a safe target is kept,
and that a multi-gear command validates its exact target. Run only these tests
and confirm that the unsafe cases fail against the current implementation.

## Task 2: Brake target implementation

**Files:**

- Modify: `virtual_tcu/logic/tcu.py`
- Test: `tests/test_race_downshift.py`

Add target-RPM projection and safe-target clamping helpers. Apply the clamp in
`_track_brake_down`, validate the actual target in `_shift_down_double`, and
record the actual crossed-gear count. Run the brake-downshift tests until green.

## Task 3: Low-gear plateau regression tests

**Files:**

- Modify: `tests/test_low_gear_rpm_ceiling.py`
- Modify if needed: `tests/test_early_upshift_rev_limiter.py`

Retain the existing true-plateau case and strengthen the rising-RPM case so it
demonstrates that a high-performance second gear cannot use the mid fallback.
Run both files and confirm the rising case fails before the implementation.

## Task 4: Plateau and anti-hunting implementation

**Files:**

- Modify: `virtual_tcu/logic/tcu.py`
- Test: `tests/test_low_gear_rpm_ceiling.py`
- Test: `tests/test_hunting.py`

Require a non-rising recent RPM trend before returning a plateau fallback.
Use `_wot_upshift_fallback` in the power-demand anti-hunting check. Run the low
gear, rev-limiter, hunting, and pending-acknowledgement regression tests.

## Task 5: Replay and full verification

**Files:** none unless a newly exposed defect requires another focused test.

Replay the supplied logs and inspect commanded shifts and predicted landing RPM.
Run `pnpm test:py`, `pnpm lint`, `pnpm typecheck`, `pnpm build:dashboard`, and
`pnpm build:electron` under Node 24. Distinguish pre-existing platform/sandbox
failures from changes introduced by this patch.
